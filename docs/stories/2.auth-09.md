# Story AUTH-09 — Role Change
**Epic:** Epic 2 — Authentication & User Management | **Points:** 2 SP | **Status:** Done

## Description
`PUT /api/v1/users/{id}/role` — role change (Admin only), cannot demote self

## Acceptance Criteria
- [x] Accepts target `role` in request body
- [x] Admin only; returns 403 for non-Admin callers
- [x] Returns 400 if attempting to change own role
- [x] Returns 404 if user not found within tenant
- [x] Valid roles: ADMIN, MOD, TEACHER (stored as `MOD`)
- [x] Returns updated user profile on success

## Technical Notes
Multi-tenancy filter ensures cannot modify users in other tenants.
