## Dev Agent Record

### Implementation Plan
- Cover is an **overlay**: `lessons.teacher_user_id` is never written. `original_teacher_user_id` is added to the table beyond the technical note's column list so the original teacher is on the assignment record itself, which is what the AC asks for and what the event payload needs.
- Eligibility rules live in `CoverEligibilityService` rather than in this service, because COVER-02 must filter candidates by exactly the same rules; sharing them means the suggestion list and the assignment check can never disagree.
- "No timetable conflict" covers two cases: the teacher already *teaching* in that slot (`lessons.teacher_user_id`) and already *covering* in that slot (another `cover_assignments` row on a lesson at the same date and period).
- Status codes: unqualified teacher, or naming the lesson's own teacher, → 400 (the request is wrong about the teacher); already-covered, busy, or forbidden → 409 (current state conflicts).
- `UNIQUE (lesson_id)` means one cover per lesson; a second assignment returns 409 rather than silently replacing.

### Debug Log
- Two endpoint tests initially failed at *setup*, not assertion: they each created a second term, which collided with the first (409). Reused the single timetable from `setUp` instead — no second term was ever needed.

### Completion Notes
- **New shared test fixture.** `AbstractEndpointTest` holds the registration/invite/role-promotion boilerplate plus Epic 7's scaffolding. `deferred-work.md` already flagged this duplication after RES-11; Epic 7 needs five endpoint tests, each also needing terms, timetables and lessons, so the copy-paste approach was no longer viable. Existing tests are left untouched and could migrate later.
- **Timetables and lessons are inserted with SQL in tests** because SCHED-01/02 have not been built, so no write API exists. The `lessons` schema from V015 already carries everything the conflict checks need (`teacher_user_id`, `schedule_period_id`, `scheduled_date`), so nothing here is blocked — but this endpoint is not exercisable end-to-end until Epic 6 populates lessons for real.
- Added one guard beyond the ACs: the lesson's own teacher cannot be assigned as their own cover (400). Without it, a no-op assignment would be accepted and would emit a misleading `COVER_ASSIGNED` event naming the same teacher twice.
- `./mvnw -o test -Dtest='CoverAssignmentServiceTest'` → 11 passed; `-Dtest='CoverEligibilityServiceTest'` → 9 passed; `-Dtest='CoverAssignmentEndpointTest'` → 16 passed.
