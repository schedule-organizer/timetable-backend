## Dev Agent Record

### Implementation Plan
- List terms: `GET /api/v1/terms?academicYearId={id}` — returns 404 if the academic year is missing for the tenant (same as create).
- Create/update body includes `academicYearId` so a term can be moved between years in one transaction with full validation.
- Ordinal uniqueness: explicit checks + DB `UNIQUE (academic_year_id, ordinal)`; API returns 409 with `ConflictException` on duplicate.
- Date bounds: term `[startDate, endDate]` must lie within academic year `[startDate, endDate]` (inclusive); term span still requires `startDate.isBefore(endDate)` like academic years.
