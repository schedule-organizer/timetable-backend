## Dev Agent Record

### Implementation Plan
- Mirrored Subject/Room CRUD patterns: tenant filter on entity, name uniqueness among active rows per tenant, soft delete via `is_active`.
- homeroomId: nullable FK to rooms; `SchoolClassService` validates room exists in tenant when provided (throws `BadRequestException` if not found or not active).
- Delete guard: `ClassSubjectHourRepository.existsByClassId` checks for allocation rows; `LessonRepository.existsByClassIdAndTenantId` checks persisted lessons (V015); either blocks soft-delete with 409. Added `existsByClassId` to the existing repository; added `existsByClassIdAndTenantId` on `LessonRepository`.
- Writes restricted to ADMIN/MOD (`@PreAuthorize("hasAnyRole('ADMIN', 'MOD')")`); GETs for all authenticated users.
- Table name `school_classes` (not `classes`) to avoid reserved word conflicts.
- Service-layer name uniqueness (active rows only) matching the pattern established in RES-01/RES-02; no partial unique index to maintain H2 compatibility.

Fixed by always inserting a fresh subject row with a unique code (`TMP{classId}`) before inserting the `class_subject_hours` guard row.
- Second test run after `rm -rf target` (stale compiled class `EmailService` without package reference caused `NoClassDefFoundError`): all 25 new tests pass, no regressions across 38 test suites.
- Revision pass (`dev-story --revise`): Project requires Java 21 (`pom.xml`); use SDKMAN `21.0.10-tem` (or equivalent) for `./mvnw test`. `ConflictDetectionServiceTest` called `term.setId()` but `Term` exposes no setter for id — switched to `ReflectionTestUtils.setField(term, "id", …)` so test sources compile.
- Second revise: addressed review finding — delete also checks `LessonRepository.existsByClassIdAndTenantId`; service + unit + integration test (`insertMinimalLessonReferencingClass`).
