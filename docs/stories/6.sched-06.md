# Story SCHED-06 — Solver WebSocket Progress Events
**Epic:** Epic 6 — Timetable & Scheduling Engine | **Points:** 4 SP | **Status:** done

## Description
WebSocket: `SOLVER_PROGRESS` and `SOLVER_COMPLETE` events on `/topic/solver/{jobId}/progress` and `/topic/solver/{jobId}/complete`; includes percent complete, current score, hard violations

## Acceptance Criteria
- [x] `SOLVER_PROGRESS` event published on each new best solution: `{ jobId, percentComplete, hardViolations, softScore, timestamp }`
- [x] `SOLVER_COMPLETE` event published on termination: `{ jobId, finalScore, scoreBreakdown, lessons[] }`
- [x] Events published to `/topic/solver/{jobId}/progress` and `/topic/solver/{jobId}/complete`
- [x] WebSocket connection requires valid JWT (STOMP CONNECT header)
- [x] Events scoped to tenant (no cross-tenant leakage)

## Technical Notes
Depends on NOTIF-01 (`WebSocketEventPublisher`). Solver listener calls publisher on each `BestSolutionChangedEvent`.

## Dev Agent Record

### Implementation Plan
- `SOLVER_PROGRESS` on `/topic/solver/{jobId}/progress` from the best-solution callback; `SOLVER_COMPLETE` on `/topic/solver/{jobId}/complete` from the final-best callback, carrying the ids whose placement actually changed.
- Reuses COVER-07's publisher and destination registry; `StompAuthChannelInterceptor` now authorizes solver topics by resolving the job's tenant from the row, exactly as it does for timetable topics. Without that, the simple broker would deliver another institution's solver progress.
- Completion also emits `LESSON_UPDATED` per moved lesson on the timetable topic, so an open grid updates from a solve just as it does from a manual drag (SCHED-12).

### Completion Notes
- **`percentComplete` is coarse** — 50 while running, 100 when terminal. Timefold's best-solution callback reports score improvements, not search progress, and there is no meaningful completion ratio to derive. A time-elapsed proxy would be misleading, so the field is honest rather than invented.
- Tests: `StompAuthChannelInterceptorTest` (17, including solver-topic authorization).
