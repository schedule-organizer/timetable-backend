# Story RES-06 — Class Subject Hours Matrix
**Epic:** Epic 5 — Resource Management | **Points:** 3 SP | **Status:** done

## Description
`GET/PUT /api/v1/classes/{id}/subject-hours` — weekly hours matrix (class × subject → periods per cycle + spread pattern)

## Acceptance Criteria
- [x] `GET` returns list of subject-hours allocations for the class (subjectId, periodsPerCycle, spreadPattern)
- [x] `PUT` replaces the full subject-hours allocation for the class
- [x] spreadPattern options: SPREAD (no consecutive), CLUSTER (allow consecutive), ANY
- [x] Returns 404 if class not found in tenant
- [x] Total periods per cycle validated against bell schedule capacity
- [x] All allocations replaced atomically on PUT

## Technical Notes
`class_subject_hours` table. Used by solver as the requirement input.

## Tasks / Subtasks
- [x] Flyway `V018__class_subject_hours_constraints.sql` (FK to `school_classes`, `spread_pattern` NOT NULL + CHECK, orphan cleanup)
- [x] DTOs `SpreadPattern`, `ClassSubjectHourItemRequest`, `ClassSubjectHoursReplaceRequest`, `ClassSubjectHourResponse`; repository query + bulk delete; `ClassSubjectHourService` + `ClassSubjectHourController`
- [x] Service tests `ClassSubjectHourServiceTest`; API tests `ClassSubjectHourEndpointTest`; fix `SubjectEndpointTest` guard row to use real `class_id` (FK)
- [x] Capacity = (non-break, non-lunch periods on default bell schedule per day) × `schedulingCycle.daysInCycle` from tenant settings (default 5)

## Dev Agent Record

### Implementation Plan
- Read policy: GET any authenticated user; PUT `ADMIN`/`MOD` (aligned with `SchoolClassController` writes).
- PUT body: `{ "items": [ { "subjectId", "periodsPerCycle" (@Positive), "spreadPattern" } ] }`; duplicate `subjectId` in one payload → 400; unknown active subject → 404 (same pattern as teacher qualifications).
- Replace: single `@Transactional` method deletes all rows for `(tenantId, classId)` then inserts the new set; sum of `periodsPerCycle` must not exceed computed capacity or 400.
- `SubjectEndpointTest.delete_whenClassSubjectHoursExist` updated: FK requires a real `school_classes` row.
