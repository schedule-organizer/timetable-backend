# Story HOL-05 — Solver Holiday Integration
**Epic:** Epic 4 — Holiday & Vacation Calendar | **Points:** 3 SP | **Status:** done

## Description
Solver integration: `HolidayService` loads holiday dates and converts them to globally forbidden period slots before each solver run

## Acceptance Criteria
- [x] `HolidayService.getForbiddenSlots(timetableId)` returns list of forbidden `PeriodSlot` objects
- [x] Holiday dates converted to all period slots on that date
- [x] Forbidden slots passed to Timefold solver as hard constraints
- [x] Solver rejects solutions that schedule lessons on holiday dates
- [x] Performance: slot loading completes in < 100ms for up to 365 holiday dates

## Technical Notes
Depends on SCHED-03. Holiday slots represented as `UnavailablePeriodPenalty` in Timefold model.

## Tasks / Subtasks
- [x] Add Timefold (`timefold-solver-spring-boot-starter`) and minimal planning model (`PeriodSlot`, `UnavailablePeriodPenalty`, `Lesson`, `TimetableSolution`)
- [x] Implement `SchediFlowConstraintProvider` hard constraint joining lessons to holiday penalties
- [x] Add `timetables` table (V011), `Timetable` entity, `HolidayService.getForbiddenSlots` / `getHolidayPenalties`
- [x] Unit tests: `HolidayServiceTest`, `HolidayHardConstraintSolverTest`

## Dev Agent Record

### Implementation Plan
- Introduced minimal `timetables` row (term + bell schedule) so a solver run can resolve holidays for a concrete timetable.
- `HolidayService` loads the term’s academic-year holiday calendar, filters dates to the term range, expands each date to non-break `SchedulePeriod` rows for the timetable’s bell schedule, and returns immutable `PeriodSlot` values.
- Timefold `UnavailablePeriodPenalty` problem facts + `Holiday slot must be free` hard constraint penalize a `Lesson` whose `PeriodSlot` matches a penalty.

### Debug Log
- `SolverConfig` constraint provider is configured via `ScoreDirectorFactoryConfig#setConstraintProviderClass`, not on `SolverConfig` directly (Timefold 1.16).

### Completion Notes
- Full test suite: 315 tests passing (`mvn test`). Holiday solver smoke tests demonstrate feasible assignment off a holiday slot and infeasible score when only forbidden slots exist.
