# Story FOUND-08 — CORS Configuration
**Epic:** Epic 1 — Foundation & Infrastructure | **Points:** 1 SP | **Status:** Done

## Description
CORS configuration scoped to known frontend origin

## Acceptance Criteria
- [x] CORS allows requests only from configured frontend origin (env var `ALLOWED_ORIGINS`)
- [x] Allowed methods: GET, POST, PUT, PATCH, DELETE, OPTIONS
- [x] Allowed headers: Authorization, Content-Type
- [x] Credentials allowed (for HttpOnly cookie refresh token)
- [x] OPTIONS preflight requests return 200
- [x] Requests from unlisted origins are blocked

## Technical Notes
Configure via `WebMvcConfigurer.addCorsMappings` or `CorsConfigurationSource` bean in Security config.
