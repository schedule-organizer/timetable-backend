# Story HOL-04 — List Holiday Dates by Academic Year
**Epic:** Epic 4 — Holiday & Vacation Calendar | **Points:** 1 SP | **Status:** done

## Description
`GET /api/v1/holidays?academicYearId=...` — return all dates (imported + manual) for a given academic year

## Acceptance Criteria
- [x] Returns all holiday dates (imported + manual) for the given academicYearId
- [x] Response sorted by date ascending
- [x] Returns 404 if academicYearId not found in tenant
- [x] All authenticated roles can read
- [x] Response includes: date, name, type, source (IMPORTED/MANUAL)

## Technical Notes
Join `holiday_calendars` → `holiday_dates` filtered by academicYearId.

## Dev Notes
- The new `source` column defaults to `MANUAL` in V010, so existing manual dates remain correct after migration
- `HolidayImportController` (base path `/api/v1/holidays`) hosts the GET endpoint; `HolidayDateService` hosts the business logic
- Tenant isolation via `findByAcademicYearIdAndTenantId` — explicit `tenantId` param consistent with other service methods in this codebase
- No `@PreAuthorize` on the GET endpoint — all authenticated roles (ADMIN, MOD, TEACHER) can read
