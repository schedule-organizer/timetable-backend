# Story FOUND-05 — JWT Security Infrastructure
**Epic:** Epic 1 — Foundation & Infrastructure | **Points:** 5 SP | **Status:** Done

## Description
Spring Security: `JwtTokenProvider`, `JwtAuthenticationFilter`, token validation, BCrypt password encoding

## Acceptance Criteria
- [x] `JwtTokenProvider` generates and validates JWT access tokens (15 min expiry)
- [x] `JwtAuthenticationFilter` extracts Bearer token from `Authorization` header and sets `SecurityContext`
- [x] Invalid/expired tokens return 401 with standard error envelope
- [x] BCrypt password encoder bean configured with cost factor 12
- [x] Public endpoints (auth routes, actuator/health) accessible without token
- [x] Spring Security HTTP security config disables sessions (STATELESS)

## Technical Notes
Use `io.jsonwebtoken:jjwt` library. JWT secret loaded from environment variable, not hardcoded.
