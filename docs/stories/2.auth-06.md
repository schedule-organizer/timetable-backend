# Story AUTH-06 — Complete Registration via Invite
**Epic:** Epic 2 — Authentication & User Management | **Points:** 4 SP | **Status:** Done

## Description
`POST /api/v1/auth/complete-registration` — consume invitation token, set password, activate user account

## Acceptance Criteria
- [x] Accepts: invitation token, new password, optional display name
- [x] Validates token exists, is not expired, and has not been used
- [x] Sets user password (BCrypt hashed), status → `ACTIVE`
- [x] Marks token as consumed (single-use) via `used_at` timestamp
- [x] Returns JWT access token + sets refresh cookie (auto-login after registration)
- [x] Returns 400 for expired or invalid token with clear error message

## Technical Notes
- Public endpoint (no JWT required) — already listed in SecurityConfig as `permitAll`
- Runs in a single transaction
- Token lookup by SHA-256 hash of the raw token from request body
- `used_at` column added to `invitation_tokens` via V004 migration
- V004 also adds `display_name VARCHAR(255)` to `users`
- Returns same `AuthResponse` shape as login/register; sets HttpOnly refresh cookie
