# Story EXPORT-07 — Subject Coverage Report
**Epic:** Epic 9 — Export & Reporting | **Points:** 3 SP | **Status:** done

## Description
Subject coverage report: actual vs required periods per class; flags under/over-scheduled subjects

## Acceptance Criteria
- [x] `GET /api/v1/timetables/{id}/reports/subject-coverage`
- [x] Returns per class × subject: required (from RES-06), actual (from timetable lessons), variance, status (ON_TARGET/UNDER/OVER)
- [x] UNDER: actual < required; OVER: actual > required
- [x] Summary: totalUnder, totalOver, totalOnTarget
- [x] Returns 404 if timetable not found in tenant
- [x] All authenticated roles can read

## Technical Notes
Joins `class_subject_hours` (requirements) with `lessons` (actuals) grouped by class + subject.

## Dev Agent Record

### Implementation Plan
- Joins RES-06's `class_subject_hours` (the requirement) against the timetable's actual lessons, grouped by class and subject.
- `variance = actual − required`; negative is UNDER, positive OVER, zero ON_TARGET.
- Readable by **all authenticated roles**, per the AC — unlike the other two reports, which are ADMIN/MOD.

### Completion Notes
- Only class/subject pairs with a stated requirement appear. A subject taught without any `class_subject_hours` row has nothing to be measured against, so listing it as "OVER by N" would be misleading.
- Tests: covered by `TimetableExportAndReportEndpointTest`.
