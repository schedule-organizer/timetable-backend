# Story EXPORT-06 — Room Utilization Report
**Epic:** Epic 9 — Export & Reporting | **Points:** 3 SP | **Status:** done

## Description
Room utilization report: occupancy percentage per period, by room type; JSON response

## Acceptance Criteria
- [x] `GET /api/v1/timetables/{id}/reports/room-utilization`
- [x] Returns per-room: roomName, roomType, occupancyByPeriod (period → occupancyPct), avgOccupancy
- [x] Also returns aggregate by room type: avgOccupancyByType
- [x] Returns 404 if timetable not found in tenant
- [x] Admin/Mod only
- [x] Occupancy = (assigned lessons / total periods in cycle) * 100

## Technical Notes
Read-only aggregation. Total periods = days × periods per day from bell schedule.

## Dev Agent Record

### Implementation Plan
- Occupancy denominators come from the timetable's own span: distinct scheduled days × the bell schedule's teaching periods (break and lunch excluded, since a room is not expected to be in lesson use then).
- Per-period occupancy is "what share of days is this room busy in this period", which is the question a timetabler actually asks; `avgOccupancy` is the room's share of the whole cycle.
- Rooms with no lessons still appear, at 0% — an unused room is exactly what this report should surface.

### Completion Notes
- An empty timetable reports `totalPeriodsInCycle: 0` and all rooms at 0% rather than dividing by zero.
- Tests: covered by `TimetableExportAndReportEndpointTest`.
