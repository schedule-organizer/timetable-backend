**Epic:** Epic 10 — Setup Templates (Post-MVP) | **Points:** 5 SP | **Status:** done

## Description
Seed: 5 built-in templates — Primary School, Secondary School, High School / Sixth Form, Language School, Vocational Centre

- [x] 5 built-in templates seeded via Flyway data migration or `DataInitializer` component
- [x] Templates: Primary School (6 periods, 5 days), Secondary School (8 periods, 5 days), High School/Sixth Form (10 periods, 5 days), Language School (6 periods, 5 days with afternoon blocks), Vocational Centre (4 periods + workshops)

- [x] Templates available in `GET /api/v1/templates` without authentication (for onboarding UI)
- [x] Idempotent seeding (safe to run on schema reset)

## Technical Notes
Seeded via `V034__seed_built_in_templates.sql` Flyway migration.

## Dev Agent Record

### Implementation Plan
- Seeded by Flyway (`V034`) rather than a `DataInitializer`, which the AC allowed: the data is static, so it belongs with the schema and gets the same versioning and replay guarantees.
- **Idempotent by construction** — each insert is guarded by `WHERE NOT EXISTS (... name ...)`, so a replay or a schema reset cannot duplicate a built-in.
- Period times are generated from each template's own lesson length, so a Vocational Centre's four 90-minute blocks and a Primary School's six 45-minute periods both come out coherent rather than hand-typed.

### Completion Notes
- `GET /api/v1/templates` is permitted unauthenticated so an onboarding UI can offer the built-ins before an account exists. With no tenant in context the service simply has nothing custom to add — the same endpoint serves both cases rather than needing a separate public one.
- Tests assert all five by name, their period counts, and that the built-in count stays at five with no duplicate names.
