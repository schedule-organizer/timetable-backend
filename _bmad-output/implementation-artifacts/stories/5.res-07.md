# Story RES-07 — Teaching Groups CRUD
**Epic:** Epic 5 — Resource Management | **Points:** 4 SP | **Status:** done

## Description
CRUD `/api/v1/teaching-groups` — groups linking teachers, subjects, and classes; support SET, MIXED, OPTION_BLOCK types; Flyway migration

## Acceptance Criteria
- [x] CRUD for teaching groups (name, type, teacherId, subjectId, classIds[])
- [x] Types: SET (one class), MIXED (multiple classes combined), OPTION_BLOCK (managed by option block)

- [x] Returns 404 if teacher, subject, or any classId not found in tenant
- [x] Prevents duplicate teacher+subject+class combinations
- [x] Soft delete — groups with lesson assignments cannot be hard deleted

## Dev Agent Record

### Implementation Plan
- Read policy: GET any authenticated user; POST/PUT/DELETE `ADMIN`/`MOD` — same as `SchoolClassController`.
- `type` is sent as a String and parsed service-side (`RoomService` pattern) so an unknown value yields 400, not a Jackson 500.
- Class-count rules per type: `SET` exactly 1, `MIXED` at least 2, `OPTION_BLOCK` at least 1 (membership count is governed by the owning option block in RES-08).
- Duplicate rule: for the same active teacher + subject, no two groups may share a class. Checked service-side across sibling groups' member classes — a DB unique constraint cannot express it because the class lives in the junction table and soft-deleted groups must not block reuse.
- Membership replace on PUT: bulk delete junction rows then re-insert, mirroring `ClassSubjectHourService.replace`.

### Completion Notes
- `DELETE` only ever deactivates (`is_active = false`) and deliberately keeps `teaching_group_classes` rows, so a group is never hard deleted and any lessons scheduled against it stay resolvable. `lessons` has no `teaching_group_id` column yet (SCHED-02/03 adds the link), so there is no assignment count to guard on today — the soft delete is what satisfies the AC.
- Deactivating a group frees its teacher+subject+class combination for reuse; covered by `delete_thenRecreate_sameCombination_isAllowed`.
- `./mvnw -o test -Dtest='TeachingGroupServiceTest,TeachingGroupEndpointTest'` → 32 passed.
