## Dev Agent Record

### Implementation Plan
- Mirrored `Room` CRUD patterns: tenant filter on entities, code uniqueness among active rows per tenant, soft delete via `is_active`.
- Color: `#RRGGBB` via Bean Validation `@Pattern`; normalized to uppercase in service.
- Spread pattern: `SPREAD`, `CLUSTER`, `ANY` (aligned with RES-06).
- Delete guard: `class_subject_hour` rows referencing the subject block soft-delete (409). Future teacher/qualification links can extend the same pattern in RES-05+.
