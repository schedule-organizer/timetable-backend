# Story EXPORT-05 — Teacher Utilization Report
**Epic:** Epic 9 — Export & Reporting | **Points:** 4 SP | **Status:** done

## Description
Teacher utilization report: periods assigned vs capacity, gap count, subject distribution; JSON response

## Acceptance Criteria
- [x] `GET /api/v1/timetables/{id}/reports/teacher-utilization`
- [x] Returns per-teacher: periodsAssigned, workloadCap, utilizationPct, gapCount (free periods between lessons), subjectDistribution[]
- [x] Sorted by utilizationPct descending
- [x] Returns 404 if timetable not found in tenant
- [x] Admin/Mod only
- [x] Response also includes summary: avgUtilization, overloadedCount (> 100%), underutilizedCount (< 70%)

## Technical Notes
Read-only aggregation query. Gap count = non-lesson periods between first and last assigned period per day.

## Dev Agent Record

### Implementation Plan
- `gapCount` is free teaching periods *between* a teacher's first and last lesson each day — leading and trailing free periods are not gaps, since a teacher who starts late simply starts late.
- `utilizationPct` is null for an uncapped teacher rather than a fabricated number, and such teachers sort last. They are also excluded from the summary averages and the over/under counts, which would otherwise be skewed by a denominator that does not exist.
- Sorted by utilization descending, then display name for a stable order.
