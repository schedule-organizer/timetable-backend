# Story AUTH-08 — Paginated User List
**Epic:** Epic 2 — Authentication & User Management | **Points:** 2 SP | **Status:** Done

## Description
`GET /api/v1/users` — paginated user list with role/status filters (Admin, Mod only)

## Acceptance Criteria
- [x] Returns paginated list of users within the authenticated user's tenant
- [x] Supports query params: `role`, `status`, `page`, `size`, `sort`
- [x] Accessible by ADMIN and MODERATOR roles only; returns 403 for TEACHER role
- [x] Response includes: id, email, displayName, role, status, createdAt
- [x] Default page size: 20; max page size: 100

## Technical Notes
- Multi-tenancy filter automatically scopes results to tenant via `TenantFilterAspect`
- `JpaSpecificationExecutor` + `UserSpecification.withFilters(role, status)` for clean filtering
- Page size capped at 100 in `UserService.listUsers()` before passing to repository
- `PagedResponse<T>` generic record wraps Spring `Page` for consistent shape
- `@PageableDefault(size=20)` on controller parameter
