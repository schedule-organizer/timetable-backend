# Story RES-04 — Teacher Profiles CRUD
**Epic:** Epic 5 — Resource Management | **Points:** 3 SP | **Status:** done

## Description
CRUD `/api/v1/teachers` — teacher profiles linked to user accounts; workload caps, max consecutive periods; Flyway migration

## Acceptance Criteria
- [x] CRUD for teacher profiles (userId, displayName, maxPeriodsPerDay, maxConsecutivePeriods, workloadCap)
- [x] Each teacher profile linked to a `User` record (FK)
- [x] `V016__create_teachers.sql` Flyway migration included
- [x] Returns 404 if userId not found in tenant
- [x] Returns 409 if user already has a teacher profile
- [x] Soft delete — teachers with active assignments cannot be hard deleted

## Dev Agent Record

### Implementation Plan
- Mirrored Room/SchoolClass CRUD: tenant filter on entity, soft delete via `is_active`, list only active profiles ordered by `display_name`.
- Create/update validate `userId` with `UserRepository.findByIdAndTenantId`; missing user → `ResourceNotFoundException` (404). Duplicate profile for same user (any `is_active`, including after soft-delete) → `ConflictException` (409); no reactivation on create (product: return 409). Update changing `userId` uses `existsByUserIdAndTenantIdAndIdNot`. `save` maps `DataIntegrityViolationException` (unique race) to 409.
- Delete: `LessonRepository.existsByTeacherUserIdAndTenantId` blocks soft-delete when persisted `lessons` reference the teacher’s user (aligns with RES-03 lesson guards).
- Writes ADMIN/MOD; GETs for all authenticated users.

### Debug Log
- `post_asMod_createsTeacher` initially 403: invite body cannot set MOD role (`InviteRequest` is email-only). Aligned `createModUser` helper with `RoomEndpointTest`: invite → complete → `GET /users` → `PUT /users/{id}/role` (MOD) → login.
- Full suite: `HolidayImportServiceTest` unnecessary stubbing on early-return tests — `lenient()` for shared `conflictDetectionService` stub in `@BeforeEach`.
